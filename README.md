# 🧠 Algoritmos de Búsqueda y Metaheurísticas 
### Máster Universitario en Inteligencia Artificial (MUIA)

Este repositorio contiene las implementaciones, análisis teóricos y resultados experimentales de diversas metaheurísticas desarrolladas en la asignatura de **Búsqueda y Metaheurísticas**.

---

## 📂 Estructura del Proyecto

El repositorio está organizado en tres bloques principales, cada uno con su código fuente, informes técnicos en LaTeX y presentaciones.

### 1. 🏝️ Biogeography-Based Optimization (BBO)
Implementación del algoritmo basado en la dinámica de migración de especies entre hábitats.
* **Código:** [Algoritmo Base](1_BBO/src/bbo.py) e [Implementación/Pruebas](1_BBO/src/implementacion.ipynb).
* **Documentación:** [Informe Técnico (PDF)](1_BBO/informe/document.pdf).
* **Presentación:** [Slides BBO](1_BBO/ppt/Biogeography-Based%20Optimization%20(BBO).pdf).

### 🐜 2. Ant System (ANTS)
Estudio de sistemas de colonias de hormigas, específicamente el **Sistema de Hormigas Elitista** para problemas de optimización.
* **Código:** [Notebook de experimentación](2_ANTS/src/ant_system.ipynb).
* **Documentación:** [Análisis Ant System (PDF)](2_ANTS/informe/build/ant_system.pdf).
* **Presentación:** [Slides Ant System](2_ANTS/ppt/Ant%20System.pdf).

### 🔍 3. Fuzzy Adaptive Neighborhood Search (FANS)
Algoritmo de búsqueda por entornos que utiliza **Lógica Difusa** para adaptar la estrategia de búsqueda de forma dinámica.
* **Código:** Localizado en la carpeta `3_FANS/src/`.
* **Documentación:** [Informe FANS (PDF)](3_FANS/informe/FANS.pdf).
* **Presentación:** [Slides FANS](3_FANS/ppt/FANS_%20Búsqueda%20por%20Entornos%20Adaptativa%20y%20Difusa.pdf).
